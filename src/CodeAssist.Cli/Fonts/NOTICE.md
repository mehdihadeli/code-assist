# Terminal Font Attribution

The CLI does not bundle a font binary. The official v3.5.1 release catalog supplies
each ZIP's published SHA-256 digest. Installation preserves every selected
archive license, notice, copyright, README and text file beside the registered
font, plus the content-pinned upstream documents in FontNotices.cs.

Those documents cover the font collection's licensing audit and the Codicons,
Devicons, extra glyphs, Font Awesome, Font Awesome Extension, Material Design,
Octicons, Pomicons, Powerline, IEC power symbols, Seti and Weather Icons sets.
Retain the installation's `.notices` directory when redistributing its font.
Patching and upstream authorship details remain in the supplied READMEs. The
collection includes MIT, OFL, Creative Commons, Apache and other terms; it is
not blanket MIT. Upstream v3.5.1 explicitly flags Font Logos as unlicensed.
Preserving the audit does not resolve that upstream permission limitation.

Sources: https://github.com/ryanoasis/nerd-fonts/releases/tag/v3.5.1 and the exact
official/upstream URLs and SHA-256 content pins in FontNotices.cs. If a required
document is unavailable or changes, setup retains ASCII before registration.
Existing/shared fonts and their attribution are not removed or rewritten.
